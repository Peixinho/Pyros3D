Why it starts dim here

WebGL2 has no compute shaders, so every probe is traced on the CPU, in the browser, under a millisecond-per-frame ceiling. On a desktop GPU the whole volume is re-solved every frame and there is no visible convergence at all.

Same algorithm either way: 294 probes ray-traced against a BVH, multi-bounce feedback so light that has bounced twice still counts, and probes that relocate themselves out of walls. The geometry is built in code from primitives, so the entire download is the module and the engine’s shaders — no scene file, no textures.
